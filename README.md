# Re Culture™ | Human Judgement With AI

An AI-Assisted Decision Can Be Complete In A System While Its Human Consequences Remain Open. This Skills-Only Plugin Helps Individuals, Teams, Enterprises, And Public Institutions Examine Purpose, Evidence, Privacy, Fairness, And The Human Decision Point. It Does Not Approve, Certify, Or Make Decisions For A Person Or Institution.

## Install From A GitHub Marketplace

This Repository Is A Marketplace Source For The Re Culture™ Human Judgement Plugin. The Public Source Is Published At https://github.com/israrulhaq7013-web/re-culture-human-judgement-plugin.

- **Codex Or ChatGPT Desktop:** Add The Repository With `codex plugin marketplace add israrulhaq7013-web/re-culture-human-judgement-plugin`. Open The Plugins Directory, Choose The Marketplace Named `re-culture-public`, And Install `Re Culture™ | ري كلتشر™` Where That Source Is Supported.
- **ChatGPT Managed Workspaces:** A Workspace Administrator Can Open Workspace Settings > Plugins > Add > Import Marketplace And Enter The Public GitHub Repository URL. The Administrator Controls Availability And Installation For Workspace Members.

This Source Is Separate From The OpenAI Universal Plugin Directory. A Public Repository Does Not Create A Global ChatGPT Install Listing. Version 0.1.0 Contains A Skill And Public Reference Files. It Has No MCP Server, Re Culture™ Data Endpoint, Or Connection To Workspace Systems. Users Should Share Only Information They Are Authorized To Provide In Their Workspace.
