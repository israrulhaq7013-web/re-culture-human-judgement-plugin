# Re Culture™ Human Judgement

An AI-Assisted Decision Can Be Complete In A System While Its Human Consequences Remain Open. This Plugin Helps Individuals, Teams And Institutions Examine A Fictional Or Redacted Situation Through Re Culture™ Public Guidance. Claude Produces The AI-Assisted Interpretation; A Responsible Human Keeps The Decision.

## Connect And Use

Install The Plugin In A Supported Claude Surface. Open Its Connectors Tab And Add The Re Culture™ Public Guidance Connector. The Public Server Requires No Sign-In. Ask In English Or Arabic For A Human Judgement Review Of A Short, Redacted Situation, Or Ask To List The Available Guidance.

The Skill Retrieves Foundation And Workflow Records; Arabic Reviews Also Retrieve Arabic Examples. Only `topic` And `language` Are Sent In Guidance Tool Arguments. The Declared MCP Server Is `https://re-culture-public-guidance-mcp.reculture-independent.workers.dev/mcp`. The Skill Requests No API Key And Calls No Separate Paid Review Agent.

## Evidence And Data Boundaries

The Review Separates Supplied Facts, Inferences And Missing Evidence, Identifies Human Consequences And Responsibility, And Offers A Specific Next Step Or Pause Condition. It Does Not Certify Compliance, Approve Decisions, Score People, Access Private Reflections Or Inspect Internal Systems. Source Records Are Versioned Snapshots; Their Hashes Do Not Prove Live Currency Or Independent Validation.

Do Not Share Secrets Or Personal Records. Your Situation Remains In The Claude Conversation Under Anthropic’s Applicable Account And Data Policies; It Is Not Included In Guidance Tool Arguments. Network Requests Still Reach The Declared Server And Its Hosting Provider. This Package Does Not Establish A Zero-Retention Or Zero-Logging Guarantee. If Required Guidance Cannot Be Retrieved, The Source-Dependent Review Pauses.
