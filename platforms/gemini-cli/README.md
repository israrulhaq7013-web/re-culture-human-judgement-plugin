# Re Culture™ Human Judgement For Gemini CLI

An AI-Assisted Decision Can Be Complete In A System While Its Human Consequences Remain Open. This Extension Helps Individuals, Teams And Institutions Examine Fictional Or Redacted Situations Through Re Culture™ Public Guidance. Gemini CLI Produces The AI-Assisted Interpretation; The Responsible Human Retains The Decision.

## Use

Install This Extension From Its Published GitHub Repository With `gemini extensions install` Followed By The Repository URL. For Local Testing After Extracting This Package, Run `gemini extensions link .` From The Extension Folder, Then Restart Gemini CLI. Check `/extensions list`, `/skills list` And `/mcp list` In The Session. Only Trust And Enable Extensions After Inspecting Their Contents.

Ask: “Use Re Culture™ Human Judgement To Review This Fictional Situation: A Manager Denies A Development Opportunity Using An AI Summary Without Checking The Evidence Or Hearing The Employee.”

The Skill Retrieves Foundation And Workflow Records In The Requested Language. Arabic Reviews Also Retrieve Arabic Examples. Only The Enumerated `topic` And `language` Values Are Included In Guidance Tool Arguments. The Public MCP Server Requires No Sign-In Or Re Culture™ API Key.

## Connections And Data

This Extension Declares One Remote Streamable HTTP MCP Endpoint: `https://re-culture-public-guidance-mcp.reculture-independent.workers.dev/mcp`. It Allows Only `list_public_guidance` And `get_public_guidance`. It Bundles No Executable Scripts, Hooks, Sub-Agents Or Installation Commands, And It Does Not Turn Off Tool Confirmations. The Instructions Do Not Authorize Other Gemini CLI Tools To Act On The User’s Behalf.

Provide Only Fictional Or Redacted Context. The Skill Instructs Gemini CLI To Keep The Situation Out Of Public Guidance Tool Arguments. Your Conversation Still Follows Your Gemini CLI Authentication, Account And Data Conditions. Network Requests Reach Re Culture™’s Declared Server And Its Hosting Provider. No Zero-Retention Or Zero-Logging Guarantee Is Made. An Instruction Is Not A Technical Guarantee Of Every Model Output Or Host Behavior.

## Review Boundaries

The Review Separates Supplied Facts, Inferences And Missing Evidence; Examines Human Consequences; Identifies Responsibility; And Returns A Concrete Human Next Step Or Pause Condition. It Does Not Certify Compliance, Approve Decisions, Score People, Access Private Reflections Or Inspect Internal Systems. Source Records Are Versioned Snapshots, Not Proof Of Live Currency Or Independent Validation.

This Is A Gemini CLI Candidate Adapted From Re Culture™ Public Guidance v0.1.4 Instructions.
